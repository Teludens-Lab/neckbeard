What happens next?

  1. After publication, download the repository using the clone command.
  2. Run the installer in your terminal. It copies your edition into your Codex skills directory.
  3. Open Codex with access to the product repository, then ask Neckbeard for a learning guide.
What access and tools does it need?

Neckbeard inspects files you make available to Codex. A running application helps verify interface workflows. Voice generation, screen recording, and editing require separate compatible tools; those services may have their own costs and permissions.

What if I already have Neckbeard installed?

Run the new distribution’s installer with --action upgrade. It backs up the previous installation, preserves the selected edition and organization configuration, and refuses changes to other managed files. Use --action uninstall for a reversible removal.

Can I use it without audio or video tools?

Yes. Written guides, tutorial scripts, and storyboards do not require media production tools. Finished recordings depend on the tools available to Codex.

Already installed? Use --action upgrade from the new distribution. Your previous installation is backed up.

A NOTE ON TRUST

Clarity includes
knowing the limits.

Code inspection is evidence. Running the workflow is stronger evidence. Neckbeard keeps the difference explicit.

Media production needs compatible recording, voice, and editing tools. The media component provides direction and templates; it does not bundle those tools. Without them, it prepares the script and production package.

No claim of learning effectiveness without evidence from learners.
