# Proposal tool: start here

Draft end-user onboarding for the supplied local CLI fixture. Your goal is to submit nonblank proposal text as `participant` and recognize the returned JSON.

1. Complete [your first submission](first-task.md).
2. Build independence with [practice](practice.md).
3. Use [troubleshooting](troubleshooting.md) to recover.

The tool returns a result for each invocation. It does not save proposals, send notifications, authenticate users, or provide a review interface. `--role` is a supplied argument, not a login. The response labels visibility and finality; it does not enforce actual sharing. Automatic translation and bulk export are roadmap items, not available commands.

Maintainers: see [verification and release limits](verification.md) and [governance record](governance.json).
